# Woodland

`layout.rs` places the clearing ramp, its trails and the lake surroundings, and publishes the lake’s shared water settings.
`source-layout.json` holds the fixed mesh poses and lake material, shoreline and recovery values.
`source-vegetation.json` holds the northern forest’s original plant poses; `source-adjacent-canopy.json` adds the adjoining grove’s canopy trees.
`ground-provenance.toml` records the source terrain comparison and corrected grid-page checksums.
