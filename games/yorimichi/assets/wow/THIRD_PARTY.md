The Rust tool uses selected crates from [benilla](https://github.com/samwhosung/benilla/tree/b396bbf69a0486b6d29829ec191145f63c363eea),
pinned to `b396bbf69a0486b6d29829ec191145f63c363eea`. Benilla offers
[MIT](https://github.com/samwhosung/benilla/blob/b396bbf69a0486b6d29829ec191145f63c363eea/LICENSE-MIT) OR
[Apache-2.0](https://github.com/samwhosung/benilla/blob/b396bbf69a0486b6d29829ec191145f63c363eea/LICENSE-APACHE).
These are dependencies fetched by Cargo, not vendored source. Preserve their applicable notices
when distributing built tools. Other dependency versions and checksums are in `extractor/Cargo.lock`.

The synthetic fixture is authored test data: it contains no retail geometry, texture or animation.
The tool bundle contains no proprietary client data, original client executable, recovered server
code, credentials or private Discord material. WoW assets and client table contents are separate
from these code licences; extracted content belongs in private output, outside public source.
