## Inputs before any receiving mutation

`prepare_track_native_equivalence.py` is a host-only staging command; it launches
neither Unreal nor Blender. It requires the immutable source result/authority and
byte-audit records, actual original/current GLBs and selected source packets, a
fresh complete current assembled source document with explicit SHA, the genuine Belmonte
material report and every report-selected texture, and clean source/receiving
checkouts. `prepare_track_source_stage.py` creates that document by the actual
`track_sources.inventory`, region discover/assembly callbacks and
`train_track_atomic_products.assemble`, consuming independent copies of the real
current proof packets/plans/export receipts and fixture inputs. It never invokes
mesh constructors or Blender. Preparation then calls the actual
`tools/belmonte_track_data.build` converter. No retained old
runtime/report may stand in for this fresh derivation. This is genuine derived
fixture data, not proof of a completed current runtime task.

The complete source proof determines membership; the new manifest cannot narrow
that census. Preparation retains the complete converted selector fields and only
remaps its relative GLB paths to independent copies. Every GLB hash must equal the
already attested source row. No Content, stamps or native packages are staged.

The actual Belmonte `parent`, `textures`, `join_parent` and `surfaces` bodies create
the genuine report-driven prerequisites in one exclusive fixture root. Every PNG
must match the genuine report's SHA256 and size before any native asset mutation.
There are no substitute textures or materials. Source closure includes the real
atmosphere/ground-grain/native helpers, not only the top-level importer.

Track importer source must match SHA256
`b311b7322b0030c1d5f4bd44e03f82f2ed092e8001389a8f6e67370119ebe892`.
The harness removes only its exact final `main()` dispatch before loading it, then

## Native boundary owned by the parent

No native command has been launched for this harness. Before any future launch,
the parent must verify its stopped receiver/caller boundary, ordinary capacity
rules and a current successful native build. Record the exact engine executable,
engine build ID, loaded module file identities and successful compile fingerprint
using the existing `current_native_build` helper. Check them again after the whole
guarded call. Source hashes alone cannot establish the compiled reader identity.

Only the existing compiled `NativeAtomicEquivalence.snapshot`, `component_policy`
and `probe` APIs are required, in `Yorimichi`; no new module or reflected function is
proposed. `StaticMeshEditor`, Interchange and ordinary production material APIs are
also required. The receiver's reader C++/header and production importer/helper bytes
must be included in the frozen input vector before launch.

Run two separately guarded, bounded UnrealScript calls, one phase each. Both use
the same fresh exclusive package paths, so observed material paths and exact native
policy need no evidence normalization. Each phase executes the actual full importer,
checks all 137 primary assets, saves/reloads them, and captures every authored saved
MeshDescription/render LOD, GPU basis/color/UV/material, cooked surface and hull,
settings/screens, actual physical box/sphere and fixture component policy.

The original phase archives every saved package and raw page before supported editor
deletion. Require whole exit0, the exact completion marker, an empty child/reporter
guard and unchanged input/source/module identities. Only then may the host preflight
every remaining file's exact recorded SHA, member/type and ancestor chain, remove
only those fixture remnants and empty owned directories, and prove physical absence.
The second phase must not run over failed, unresolved or partially cleaned state.
No UE-side manual file deletion is permitted. A failed run remains preserved for
explicit recovery; this draft has no automatic retry path.

The initial budget proposal is the normal 10GiB full reservation, three supported
shader/compiler workers and a 900-second work deadline per phase, with separately
bounded queue time and progress. These are ceilings, not timing/peak claims. Parent
admission remains authoritative. Native pages/import progress must remain visible.

## Comparisons and coverage limits

The public comparator requires all 137 original/current descriptors, all 362 LODs,
exact generic source/GPU/cooked/hull/material/settings/source-presence comparisons,
and exact physical bounds for both single-LOD and coordinated LOD meshes. Capture
controls derive from the original source geometry and are bound before launch, not
chosen after observing desired hits. Blocking selectors require positive and negative
selected-component ray/capsule checks. NoCollision selectors require negative checks
at actual geometry. These fixture component flags follow the runtime selector input;
they are not observations of a spawned production owner.

`ABelmonteTrack::Spawn`/`Initialize` are not reflected. This Python fixture must not
claim production placements, real HISM batching, tunnel light/exposure behavior,
character/vehicle traversal, packaged cook or normal native-owner task reuse. No
extra native bridge is requested merely to broaden this checkpoint. Results retain
`complete:false`, `native_complete:false` and explicit fixture scope.

The source-only draft includes `run_track_native_equivalence.py` as the explicit
parent-invoked host launcher/finalizer. It checks `current_native_build` before and
after each normal guarded phase, binds the spec SHA in the exact native marker,
requires clean pinned source/receiver identities and successful whole/empty guard,
and preflights exact residual bytes/types and allowed directory chains before any
host unlink. Current phase refuses until original host finalization and physical
absence are proven. The actual source importer delete calls have a recording-only
observer so temporary GLTF packages also enter the exact owned cleanup census;
the real editor API and its return value are unchanged.

Before a launch, source review and focused pure fault-injection checks remain
necessary for this new draft. The parent alone owns the stopped receiver boundary,
launch and admission decision. No source preparation, child marker or plan is
acceptance evidence.
