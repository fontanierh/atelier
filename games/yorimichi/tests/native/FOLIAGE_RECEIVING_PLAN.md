# Paired foliage receiving fixture (source preparation, no native result)

This fixture consumes the frozen original/current source proof: 102 byte-identical
FBXs/source packets and 18 exact manifests. The 18 normal native owners assemble
84 authored LODs into 18 base meshes and save another 66 source-LOD packages.
Native comparison therefore covers 84 packages and 150 saved/render LOD pages.
The 18 Seed files remain bound source evidence; the actual shared importer never
reads or imports them. They must not become invented native packages.

Both phases execute the same SHA-bound production `shared_materials.main`, then
every production `import_foliage.main` and `apply_lods` body. All 22 catalogue
textures are independent copies, with genuine original bytes/identities before
and after copying/receiving. Materials include actual foliage/grass/wind/fade,
painterly, atmosphere, see-through and crown graph functions; no replacement shaders
or fabricated foliage interface are permitted. The actual required installed engine
DitherTemporalAA function and companion presence/absence are bound inputs. The actual material owner produces
its interface from the saved material assets.

The only source adaptation is a finite exhaustive literal namespace translation:
`/Game/Japan` and `/Game/SeeThrough` become children of one exclusive fixture root;
`Japan/Assets` in the package-header check maps consistently. Every permitted file
is byte/SHA-bound, final dispatch removal is exact, reverse translation must recover
its full original AST, and all remaining project paths refuse before mutation.
Inputs and output roots are explicit fixture paths. No production Content is created.

The existing `atomic_equivalence_capture` and compiled `NativeAtomicEquivalence`
APIs capture real saved MD, render/GPU attributes, cooked surfaces/hulls, every LOD,
material/settings/screens and actual box/sphere/component bounds. Each real saved
package is reloaded first. Near tree fixture components use the current QueryOnly
policy and receive actual-component complex positive/negative ray/capsule checks.
All current manifests disable trunk hulls: the original source proof retains its
10 serialized UCX hulls, while both unchanged native owners clear them. Simple
queries must hit the seven ComplexAsSimple trees and miss the three Default/no-hull
trees at real surface controls;
bush/grass components use current NoCollision and negative probes at real geometry.
Unplaced source-LOD packages are captured with explicitly NoCollision fixture
components, never claimed as additional runtime owners. Production placements,
backdrop policy, HISM grouping/wind visual behavior, gameplay, packaged cook and
normal native-owner receipt reuse are outside this proof. The fixture refuses an
inherited task/receipt nonce rather than altering or publishing normal evidence.

Original and current run sequentially at the same exclusive logical package paths.
Complete successful capture and external-reference preflight precede supported editor
retirement; host exact-file cleanup requires whole exit0, empty independent guard,
unchanged source/module/input identities and exact residual SHA/type/membership.
Failure only detaches/destroys recorded fixture actors, preserves the original
exception and leaves partial packages recorded for explicit recovery. The second
phase refuses any original fixture remnant.

The private UserDir/DDC/nowrite envelope and actor/package safety helpers are reused
byte-identically from Track helper `f55b1847d` (the full engine-log correction). Each phase has its own private user
folder and both share one private persistent proof DDC; installed pak is read-only,
Zen auto-launch/default fallback are disabled, and actual startup command/path/log
verification precedes fixture asset writes. Explicit phase `-abslog` engine logs
are flushed before reading and SHA-bound/rechecked at exit; stdout can omit verbose
graph messages and is not used for that proof.
This is old-module startup-log evidence, not C3 native graph introspection. Cache
contents/hits certify nothing. No shared services/settings are edited; no benchmark.

Preparation is host-only with no native launch. It requires a stopped/stable producer
before copying its live current products, the frozen proof authority and complete
current source/tool/material identities. Native admission remains with the parent at
its stopped receiver boundary. Initial proposal: normal fully reserved 10 GiB,
900-second work/1200-second queue deadlines per phase; measured demand may require
a larger supported full reservation, never a lowered or bypassed guard.
