# Fonts

Noto Sans JP variable font from the Google Fonts repository, distributed under the included SIL Open Font License.
It sets the Japanese lettering on Hidamari's signs and banners (`hidamari/build.py`, `kit/_lettering.py`) and the
Mega Park's signs (`megapark/sign.py`).

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
Downloaded 2026-09-06. Font file and license are preserved without modification.
