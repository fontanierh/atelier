# Southwest detour

The lane leads through the fishing village to a coconut stand and beach. A simple
sailboat now connects the coast with the island and its temple. Kiteboarding was
removed; its old reference sheets remain in the historical art review folders.

Landscape and static props are generated by `layout.py` and `build.py`. The active
boat model, controller, reference and regression checks are documented in
`../sailboat/README.md`. Run `japan/run.sh southwest` for the scenery and
`japan/run.sh sailboat` for the playable boat.
