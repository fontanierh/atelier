# Whole final queries and bounded native ground

Belmonte's generated NorthCountry and NorthApron contain more than one million and
160,000 triangles respectively in the inspected production report. Splitting only
committed buildings leaves these preparation monoliths untouched.

The ordinary region producer retains each complete final ground surface under
`belmonte/ground/glb/`, with exact bytes and logical owner names. It publishes complete
membership, hashes, bounds, triangle counts and the authored region origin. Natural
terrain remains under its existing separate ownership; these queries use final carved
geometry. The producer emits bounded native rendering/collision members through the
same GLB partitioner as the static models, at most 32,768 triangles per piece. Small
ground models retain their exact native report entries, names and bytes.

`world.belmonte.ground` verifies the full query inventory and publishes the named
`belmonte.ground` product. The map reads this product and the canonical whole extension
surfaces. Gondola ground selection uses the published logical surfaces and actual file
paths, so removing a native parent cannot strand a route query. Its legacy deferred
collector declares the selector file and selected geometry explicitly; a cutoff keeps
unconsumed metadata out of downstream query identity. The framework prohibition on
mixing deferred collectors with product reads is preserved.

Native parents retire through the existing completed-membership/reference preflight.
The natural-ground railway query paths remain unchanged. Native import, runtime placement
and collision still consume every piece. Apron/terrain pieces remain ground-owned for
structural clearance exclusion; Country geometry retains its previous structural-query
participation. This change does not exempt geometry by name from foliage preparation.

This is a source implementation pending ordinary generated export/native import and
seam/traversal validation at a stopped owner boundary after the first foliage capture.
No active receiver is changed and no memory, draw-call, cook-byte or FPS improvement is
claimed by the source checks. Other regional monoliths and finer generator layering
remain separate work.
